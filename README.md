# eportfolio

Brian Yue's ePortfolio, live at **https://brianyue.me**.

## How it's hosted

- **brianyue.me** is served by **Cloudflare Workers** (Workers Builds), straight from this repository's `main` branch. Any change pushed to `main` is live in about a minute. `wrangler.jsonc` configures it, and `.assetsignore` keeps the scripts, READMEs and full-size photo originals off the public site.
- **Never put `[skip ci]` (or `[ci skip]`) in a commit message.** Both GitHub and Cloudflare skip that commit entirely.
- **GitHub Actions** (`.github/workflows/deploy.yml`) runs after every push. It organizes the photo gallery, saves the result back to `main` (which Cloudflare then publishes), and updates a mirror at byue2006.github.io/eportfolio. Every page names brianyue.me as its main address, so search engines treat the mirror as a copy.
- See each run's progress on the **Actions** tab. A green check means it worked.

## Screen sharing in interviews

- Press **P** on any page for **present mode**: no motion, larger text, light theme, the menu bar stays put, and **→ / ←** (or Space) step through the page section by section. It stays on across pages; press **P** again to turn it off. Opening a link with `?present` also turns it on.
- Click any figure to show it full screen; **→ / ←** flip through the figures in that section. On drawings, **click the sheet to zoom** to the spot you clicked; click again to zoom out.
- The shear-force balance's five sheets are also one PDF: `drawings/shear-balance-drawing-package.pdf`.
- Share a single browser window about 1280–1440 px wide rather than your whole screen.

## Personal page: volleyball, basketball, music, photography (self-organizing)

brianyue.me/personal has a tile for each category, then a section per category with its own photo grid.

- **Folders:** `personal/volleyball/`, `personal/basketball/`, `personal/music/`, `personal/photography/`. Upload photos into the right one on GitHub (**Add file → Upload files → Commit changes**) and they appear about 2 minutes later. JPG, PNG, WebP and iPhone HEIC all work, up to 25 MB each.
- **Section text, order, links and cover photos:** `personal/categories.js`. A category with no photos and no text shows as "Coming soon" on its tile and has no section yet.
- **Captions:** taken from the file name, or edited in `personal/gallery.js` (edits are kept). Newest photos come first, by the date taken.
- **New category:** make a new folder (it appears automatically), then add an entry for it in `categories.js` to give it a description and position.
- **Behind the scenes:** `tools/build_gallery.py` (run by the GitHub Action) makes 900 px and 2000 px copies in `personal/_web/` and rewrites `gallery.js`.
