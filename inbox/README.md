# Inbox: drop files here for Claude

Anything in this folder is private to the repository. It is **not** shown on brianyue.me until Claude sorts it.
Drop files in, then tell Claude "I uploaded files to the inbox". Claude renames, crops and converts them, puts each one where it belongs, and clears the inbox.

## How to upload

1. Go to https://github.com/byue2006/eportfolio/upload/main/inbox
2. Drag in your files (photos, logos, PDFs: any format, up to 25 MB each, up to 100 at once).
3. Click the green **Commit changes** button at the bottom.
4. Tell Claude in chat.

File names don't matter, but a hint helps, e.g. `portrait.jpg`, `playseat-car.jpg`, `aiaa-talk.jpg`.
